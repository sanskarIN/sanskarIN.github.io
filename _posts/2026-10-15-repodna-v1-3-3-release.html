RepoDNA v1.3.3: Making Repository Analysis Safer and More Reliable

October 15, 2026

RepoDNA v1.3.3 is now available.

This patch release focuses on improving the reliability, correctness, and safety of RepoDNA's existing features.

RepoDNA is my open-source, local-first repository intelligence project. It helps developers understand codebase architecture, dependencies, development history, security and quality signals, and repository evolution through evidence-backed analysis.

What's improved?

Safer WebAssembly CLI: The command-line launcher now validates missing values, unsupported settings, incorrect command flags, and repeated arguments before loading the WebAssembly engine.

Protected analysis files: Generating reports or Project DNA cards can no longer overwrite the input analysis through an identical output path or a hard-link alias.

Reliable documentation: Relative links and image paths inside raw HTML are processed more consistently, and malformed URL encoding results in a diagnostic rather than a crash.

Security updates: The Rust TLS dependency has been updated to rustls 0.23.46, addressing four documented security advisories.

Expanded regression coverage: New tests help protect these fixes against future regressions.

Explore the release

Version 1.3.3 is available through the official GitHub Releases page.

The project also continues to offer browser-based analysis, desktop applications, command-line tooling, generated reports, and shareable Project DNA cards.

The browser version can analyze local folders and archives without uploading their contents.
