EyeZen v1.2.0: Now Available on the Web

EyeZen v1.2.0 has officially been released, marking a new milestone in the development of this open-source, local-first workspace customization application.

The biggest addition is EyeZen Web, a browser-based edition that brings themes, workspace profiles, break reminders, scheduling, and locally stored preferences to the web.

Users can choose from 10 appearance themes and 9 starter profiles, create custom profiles, configure their routines, and export settings as JSON backups.

This release also introduces a dedicated documentation website covering features, installation, compatibility, privacy, architecture, and troubleshooting.

The desktop application remains available for Windows, macOS, and Linux, with additional native functionality on supported systems.

Try EyeZen Web: https://sanskarin.github.io/EyeZen/
