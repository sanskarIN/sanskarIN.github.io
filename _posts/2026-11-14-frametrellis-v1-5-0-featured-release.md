## FrameTrellis v1.5.0 Released — Source Monitor, Flexible Exports and More

<strong>Published:</strong> November 14, 2026

<strong>Category:</strong> Open Source / Software Releases

FrameTrellis v1.5.0 is now officially available as a featured stable release on GitHub.

Built using C++20, Qt 6, MLT and FFmpeg, FrameTrellis is a free, open-source video editor focused on non-destructive editing and local media processing.

### What's New?

#### Source Monitor and Timeline Editing

The new Source Monitor allows precise In/Out selection before adding material to the timeline.

Additional features include synchronized video/audio insertion, clip replacement, ripple editing and improved navigation.

#### Advanced Exporting

FrameTrellis now supports export frame rates independent of project FPS, selected-range export, sequential delivery presets, and 1440p/4K creator output options.

#### Audio Improvements

Per-clip stereo balance enables independent control over left/right audio distribution, alongside existing volume and fade adjustments.

#### Improved Subtitle Tools

New features include WebVTT import, subtitle cue splitting and merging, timing stretch and frame alignment.

#### Project Recovery

Batch missing-media relinking, safer compatibility checks and improved recovery tools help editors manage projects whose source files have changed location.

#### Stability Improvements

The release includes additional diagnostics, preview and thumbnail improvements, render-process isolation and expanded platform testing.

### Built for Local Editing

FrameTrellis does not require cloud processing, an account or telemetry.

The source code is publicly available under GPL-3.0-or-later.
