## LangSteps v1.1.0 Released: Go, SQL &amp; C# Learning Paths

<strong>Published: October 15, 2026</strong>

LangSteps v1.1.0 is officially released, marking another milestone for the open-source programming education platform.

This update introduces <strong>45 new guided lessons</strong> and expands the supported learning paths from seven to ten.

### What's New?

Three new learning paths join LangSteps:

<strong>Go Mastery:</strong> 15 lessons covering Go fundamentals, interfaces, error handling, concurrency, channels, testing and HTTP services.

<strong>SQL Mastery:</strong> 15 PostgreSQL-oriented lessons covering queries, joins, transactions, window functions, indexing and secure database practices.

<strong>C# 13 / .NET 9 / <a href="http://ASP.NET" rel="noopener noreferrer">ASP.NET</a> Core:</strong> 15 lessons covering modern C#, LINQ, asynchronous programming, Minimal APIs, dependency injection, security and testing.

### Improved Learning Experience

Each new learning path provides searchable lessons, category filtering, code examples, practice exercises, copyable code, direct lesson links and locally saved progress.

The release also improves automated testing, PWA cache handling, curriculum synchronization and optional API safeguards.

LangSteps continues to provide structured programming resources through its open-source website. The new code examples are learning materials rather than hosted code execution environments.
