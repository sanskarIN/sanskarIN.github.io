## RepoDNA v1.4.0 Released: A New Visual Identity and Better Application Experience

<strong>Published: October 15, 2026</strong>

RepoDNA v1.4.0 is officially available on GitHub, introducing an original visual identity alongside accessibility, usability, and reliability improvements.

RepoDNA is an open-source, local-first repository intelligence platform that helps developers understand codebase architecture, dependencies, history, quality signals, and software evolution.

### A new identity for RepoDNA

The release introduces a hand-authored SVG logo inspired by the structure of DNA and the relationships within code graphs.

The new visual identity uses a navy, blue, and teal color palette, with matching application icons and a vector wordmark.

These changes establish a consistent identity across the project.

### Improved startup experience

RepoDNA now provides branded startup screens for the web and desktop applications.

The implementation displays the branding during initialization without intentionally extending loading time.

Keyboard focus restoration has also been improved when transitioning from the startup screen to the main content.

### Reliability and documentation improvements

The release fixes handling of additional question marks within URL query values.

Documentation has been corrected to reference the maintained official RepoDNA GitHub Action.

Additional regression checks cover branding behavior and support links.

### More ways to support development

<a href="http://PayPal.Me" rel="noopener noreferrer">PayPal.Me</a> has been added as another optional way to support the open-source project.

Other existing contribution and support options remain available.

### Still local-first

Although RepoDNA now has a new appearance, its core purpose has not changed.

Developers can continue exploring their repositories through local-first analysis, architecture visualization, dependency insights, Git history, code-quality signals, and generated reports.

Optional AI explanations remain an additional capability rather than a requirement.

### Availability

RepoDNA v1.4.0 provides downloads for supported Windows, Linux, and macOS systems, along with command-line, WebAssembly, container, npm, and browser-based workflows.
