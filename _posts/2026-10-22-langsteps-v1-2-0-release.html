LangSteps v1.2.0 Released — Learn 10 Programming Technologies Online for Free

Published: October 22, 2026 | Author: Sanskar

I'm happy to announce that LangSteps v1.2.0 has officially been released and is available online for everyone.

LangSteps is my open-source programming education platform, designed to make learning software development easier, more structured, and accessible without paid subscriptions.

Visit LangSteps: https://sanskarin.github.io/LangSteps/

Learn 10 Programming Technologies

LangSteps brings together learning resources for:

  1. HTML
  2. CSS
  3. JavaScript
  4. React
  5. Python
  6. TypeScript
  7. Rust
  8. Go
  9. SQL
  10. C# and .NET

The platform includes practical tutorials, code examples, quizzes, and various learning tools.

What's New in v1.2.0?

This release focuses on improving the overall learning experience and strengthening the platform's technical foundations.

TypeScript-Powered Improvements

Shared TypeScript-powered interfaces provide better lesson searching, navigation, and progress continuity, particularly across Go, SQL, and C# learning paths.

Improved Learning Experience

Lesson navigation has been refined with better browser history integration, deep linking, and keyboard interactions.

Expanded Developer Resources

The Web API learning guide now includes 15 searchable APIs with examples and official documentation references.

Better Offline and Mobile Support

Improved caching helps previously visited learning resources remain usable offline where supported.

Mobile layout fixes also make long code examples easier to navigate on smaller screens.

More Reliable Functionality

The release includes improvements to code previews, accessibility, curriculum validation, and automated browser testing.

Free and Open Source

LangSteps is available publicly through GitHub Pages.

Learners can open the website and begin exploring lessons without an account.

The project's source code is also publicly available, making it possible for developers to inspect the implementation, report issues, and contribute improvements.

What's Next?

Future development will continue to focus on improving educational content, developer tools, accessibility, and the overall learning experience.

Community suggestions and contributions are welcome.
