CampusCore v1.0.0 Officially Released

I'm excited to announce the official release of CampusCore v1.0.0, the first stable version of my open-source student and academic management system.

CampusCore aims to simplify academic operations by bringing essential student, staff, and administrative workflows together in a modern application.

Key Features

  • Student and guardian records
  • Enrollment, classes, sections, and academic years
  • Attendance and leave management
  • Marks, grades, and report cards
  • Timetables and announcements
  • Staff management and role-based access
  • Dashboards, reporting, search, and exports
  • Responsive Web/PWA with light and dark themes

Technology

CampusCore is developed using ASP.NET Core 9, React 19, TypeScript, Entity Framework Core, and PostgreSQL.

It uses a modular architecture designed to support future development and maintenance.

Release Availability

Version 1.0.0 provides downloadable API-server packages for Windows, Linux, and Apple Silicon macOS, along with the production Web/PWA bundle.

These are self-hosted deployment components that require a configured backend environment and PostgreSQL database.

An Android debug build and a developer-installable browser companion are also included for testing and development purposes.

Open Source

CampusCore is available under the MIT License.

Developers are welcome to explore the source code, contribute improvements, submit issues, and suggest new features.
