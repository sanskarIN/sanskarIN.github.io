## RepoDNA v1.4.3 Released: A Better Desktop Experience, Safer Exports, and More Reliable Analysis

<strong>Published: October 23, 2026</strong>

RepoDNA v1.4.3 is officially available as a stable release.

This version introduces several improvements to the application experience, repository exploration, analysis reliability, and software distribution.

RepoDNA is an open-source, local-first tool that helps developers understand repository architecture, dependencies, change history, complexity, and other important characteristics.

### What's new?

#### A new What's New experience

RepoDNA now includes a dedicated What's New section accessible from the sidebar.

After installation or an update, the application can present a dismissible announcement explaining the installed version's changes. The experience works offline.

#### Desktop improvements

The Windows desktop application opens in a smaller, centered, resizable window, making it easier to use alongside other development tools.

#### Filtered findings export

Users can export currently filtered findings to CSV, including matching results outside the visible page.

The export includes spreadsheet-safety protections.

#### Advanced file filtering

The Files explorer now offers state filters for generated, vendored, binary, skipped, and ordinary files.

These controls help developers explore larger or more complicated repositories.

#### Browser reliability improvements

Version 1.4.3 improves WebAssembly initialization, analysis progress updates, worker handling, session recovery, and exported filenames.

#### Security and release improvements

The release strengthens package publishing requirements, dependency checks, Windows installer validation, and release artifact integrity.

It also introduces several fixes for browser session data, API response handling, URL token cleanup, and findings display order.

### Available platforms

RepoDNA supports Windows, Linux, macOS, and web-based workflows.

Desktop installers, portable command-line builds, WebAssembly packages, containers, and npm packages are available through the project's release and distribution channels.
