## FrameTrellis v1.3.0 Released — Safer, Smarter Video Editing

<strong>October 25, 2026 | By Sanskar</strong>

FrameTrellis v1.3.0 has officially arrived as a stable release on GitHub!

This release introduces important improvements to project safety, media management, timecode navigation, rendering diagnostics, and documentation.

FrameTrellis is a free and open-source desktop video editor built using C++20, Qt 6, MLT, and FFmpeg.

### What's new in v1.3.0?

#### Safer editing

The release adds stronger checks to help prevent accidental overwriting of project files or referenced source media. It also improves duplicate-media handling and the detection of externally modified files.

#### Smarter media management

The media bin now supports searching by filename or path and filtering imported assets by video, audio, or image type.

#### Precise timeline navigation

A new Go to Timecode dialog, accessible using Ctrl+G, allows editors to navigate directly to a specific sequence frame.

#### Better rendering diagnostics

The headless renderer introduces read-only project inspection and stronger safeguards around output destinations, cancellation, and helper communication.

#### Improved documentation

The documentation website now includes guide filtering, section navigation, copyable code examples, and accessibility improvements.

### Built around local-first editing

FrameTrellis does not require accounts, cloud uploads, subscriptions, advertising, or telemetry.

Its existing editing capabilities include multi-track timelines, trimming, splitting, transitions, audio adjustments, PNG title overlays, autosave, undo/redo, and MP4 export.

The application remains open source under the GPL-3.0-or-later license.

### Download FrameTrellis v1.3.0

The stable release provides a Windows x64 installer and portable ZIP.

Windows 10 (1809 or later) and Windows 11 are supported. Linux builds are available from source, while macOS support remains planned.

The Windows packages are unsigned; users should verify the SHA-256 checksums published alongside the downloads.
