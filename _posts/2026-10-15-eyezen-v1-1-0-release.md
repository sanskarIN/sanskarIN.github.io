## EyeZen v1.1.0 Released — Smarter Breaks, Better Routines &amp; Reliability Improvements

<strong>Published: October 15, 2026</strong>

EyeZen v1.1.0 is officially available, bringing improvements to the reliability, usability and customization of the open-source desktop application.

EyeZen helps users personalize their workspace, manage comfort preferences, switch between profiles and configure break reminders through a local-first experience.

### What's New?

#### Timed Break Prompts

A new optional in-app break prompt lets users take a timed pause, finish early or dismiss the prompt.

#### Improved Workspace Profiles

Profile management is more reliable, with safer editing and improved handling when switching or deleting profiles.

#### More Dependable Reminders

Reminder handling has been improved for situations where the computer wakes or the application returns to focus.

#### Stronger Data Reliability

The release introduces stricter configuration validation, safer import handling and additional recovery mechanisms for local settings.

#### Expanded Testing

More automated tests and reproducible release builds help improve the development and release process.

### Supported Downloads

EyeZen v1.1.0 provides installer packages for Windows x64, macOS Apple Silicon and Linux x86_64.

The packages are currently unsigned, and behavior may vary across desktop environments.

### Built With Modern Desktop Technologies

EyeZen uses Rust, Tauri 2, React, TypeScript and Vite.

The application is open source under the Mozilla Public License 2.0 and does not require a cloud account for its core functionality.

Native monitor brightness and hardware color-temperature adjustment are not implemented in this version.
