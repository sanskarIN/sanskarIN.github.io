FrameTrellis v1.1.0 Released: New Editing Features and Improved Reliability

Published: October 15, 2026

FrameTrellis v1.1.0 is officially available, introducing new editing capabilities, rendering options, and quality improvements to the open-source desktop video editor.

Built with C++20, Qt/QML, MLT, and FFmpeg, FrameTrellis focuses on precise multi-track editing and local-first media processing.

What's New in FrameTrellis v1.1.0?

Faster Editing with Clip Duplication

Users can now duplicate selected timeline clips with Ctrl+D, the Edit menu, or the timeline toolbar.

The duplicated clips preserve their original source trims and adjustments, making repeated edits more convenient.

Create Custom Title Overlays

The application now provides a built-in tool for generating transparent PNG titles with configurable text colors and font sizes.

Generated titles can be added to the timeline, positioned, and trimmed just like other image clips.

Container-Based Headless Rendering

A headless renderer is now available for compatible projects, providing new possibilities for automated rendering workflows.

Better Testing and Compatibility

Version 1.1.0 expands automated testing across important editing operations and project management workflows.

The release has passed Windows and Linux continuous integration, static analysis, sanitizer checks, and Windows package verification.

Projects created with FrameTrellis v1.0.0 remain compatible.

Local-First Video Editing

FrameTrellis is designed to operate without cloud processing.

It provides:

  • Non-destructive editing
  • Multi-track video and audio timelines
  • Real-time playback and preview
  • Audio and picture adjustments
  • MP4 exports
  • Project autosaving and crash recovery
  • An account-free, telemetry-free experience

The software is distributed under the GPL-3.0-or-later open-source license.
