## SudokuNova v0.2.1 Released — Windows Desktop Improvements

SudokuNova v0.2.1 is officially available on GitHub!

This update improves the desktop experience of SudokuNova, my open-source, offline-first Sudoku application built with Kotlin and Compose Multiplatform.

### What's new in v0.2.1?

The release introduces several Windows-focused improvements.

<strong>Native desktop menus:</strong> The new Game and Help menus provide convenient access to essential actions and project resources.

<strong>Keyboard shortcuts:</strong> Use Ctrl+N for a new puzzle, Ctrl+Z to undo, Ctrl+M to toggle notes, and Ctrl+H to request a hint.

<strong>Improved desktop layout:</strong> The application opens at a more comfortable default size and supports resizing.

<strong>Better Windows installation:</strong> The MSI installer now includes improved installation options and Start-menu integration.

<strong>Release verification:</strong> Additional checks help validate installer metadata and distribution artifacts.

### Available downloads

The GitHub release includes desktop packages for Windows, macOS, and Linux, alongside a browser distribution ZIP and development/testing artifacts for Android and iOS.

Production signing and some platform-specific compatibility checks remain separate release considerations.
