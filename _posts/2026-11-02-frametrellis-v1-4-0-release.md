## FrameTrellis v1.4.0 Released — Advanced Timeline Editing, Keyframes and Subtitles

<strong>Published:</strong> November 2, 2026<br>
<strong>Author:</strong> Sanskar<br>
<strong>Category:</strong> Open Source / Software Releases

FrameTrellis v1.4.0 is now officially available as a stable release on GitHub.

This version introduces a substantial collection of video editing improvements, making FrameTrellis more capable for creators who prefer a free, local-first desktop editor.

### What's New?

#### Advanced Timeline Editing

FrameTrellis now includes more flexible multi-track editing operations, precise clip navigation, slip and roll editing, track management, and persistent timeline markers.

#### Keyframe Animation

The editor now supports keyframes for audio volume, opacity, position, scale and rotation, enabling animated adjustments over time.

#### Subtitle Support

Users can work with subtitles directly in the editor, import and export SRT files, export WebVTT files, and optionally burn captions into exported videos.

#### Creator-Focused Exports

New H.264/AAC MP4 presets support creator workflows up to 4K, alongside lower-resolution draft and review options.

#### Improved Project Safety

Additional project validation and safer save operations strengthen editing reliability.

### Built for Local Editing

FrameTrellis is developed with C++20, Qt, MLT and FFmpeg.

It continues to prioritize local video editing without requiring user accounts, cloud processing or telemetry.

The source code remains publicly available under the GPL-3.0-or-later license.

### Download v1.4.0

The Windows x64 installer and portable ZIP can be downloaded from the official GitHub release.

Linux users can build from source.
