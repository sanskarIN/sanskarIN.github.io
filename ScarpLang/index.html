Engineering direction

The project is being developed incrementally, with documented behavior and release verification.

  • Language foundations

    Types, functions, control flow, collections and diagnostics are evolving through published pre-releases.

  • Numerical and AI-oriented computing

    Numerical primitives are part of the broader goal of making computational programming approachable.

  • Systems and native execution

    Native code generation and low-level programming are ongoing engineering directions. Experimental support is not a promise of a stable ABI or general native compilation.
