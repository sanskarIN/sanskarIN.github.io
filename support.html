Contribute to open source

Support does not have to involve money. Every useful contribution matters.

  • Test and report

    Try releases and report reproducible bugs or compatibility problems.

  • Improve code and docs

    Read project contribution guidelines and propose focused fixes, tests, examples, or documentation improvements.

  • Share and follow

    Star useful repositories, share projects with interested developers, and offer constructive feedback.
