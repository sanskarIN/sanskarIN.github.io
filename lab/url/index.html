Enter text and choose Encode or Decode.

Up to 32,000 characters. Ctrl/Cmd + Enter encodes.

The tool never sends your input to a server or stores it.

Which mode should I use?

URL component converts reserved characters as well as spaces, which is useful for query parameter values. Whole URI preserves URL punctuation such as slashes, question marks, and ampersands while encoding characters like spaces.

This is percent-encoding, not application/x-www-form-urlencoded decoding: a plus sign is treated as a literal plus, not a space.
