Tools you can use today

These utilities run in your browser. No account, API key, or installation is required.

  • {% include link.html url="/lab/json/" label="JSON Formatter & Validator" class="text-link" arrow=true %}

    Validate, format, and minify JSON. Copy the result without sending your content to a server.

    Available now · TypeScript · Browser-only

  • {% include link.html url="/lab/regex/" label="Regex Tester" class="text-link" arrow=true %}

    Test JavaScript patterns, flags, capture groups, and match positions inside a time-limited browser worker.

    Available now · TypeScript · Browser-only

  • {% include link.html url="/lab/diff/" label="Text Diff Checker" class="text-link" arrow=true %}

    Compare two text versions, inspect line additions and deletions, and copy a text-based diff.

    Available now · TypeScript · Browser-only

  • {% include link.html url="/lab/url/" label="URL Encoder & Decoder" class="text-link" arrow=true %}

    Encode and decode URL components or whole URI strings, with clipboard support and no upload.

    Available now · TypeScript · Browser-only

  • {% include link.html url="/lab/timestamp/" label="Timestamp Converter" class="text-link" arrow=true %}

    Convert Unix seconds, Unix milliseconds, ISO 8601, and local time with explicit timezone handling.

    Available now · TypeScript · Browser-only

  • {% include link.html url="/lab/contrast/" label="Color Contrast Checker" class="text-link" arrow=true %}

    Check WCAG 2.2 contrast, generate accessible text palettes, preview colors, and export CSS or JSON.

    Available now · TypeScript · Browser-only

Built for everyday development

  • Private by design: the tools process content locally, without uploading it.
  • Accessible: keyboard-friendly controls and clear validation feedback.
  • Lightweight: no heavyweight runtime or third-party service is needed.

More utilities may be added as they are implemented and tested.
