    About this tester

    Matching is performed inside a temporary browser worker, which is terminated after the time limit. This limits how long a complex expression can block the tester. Results are rendered as text, never as HTML.

    Pattern behavior follows your browser's JavaScript engine. This tool is for testing patterns, not for processing untrusted expressions on a production server.
