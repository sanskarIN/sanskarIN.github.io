How posting works

  1. Open the form

    Select "Write a post". The form opens on GitHub, where the blog's posts are stored, so you need a free GitHub account.

  2. Write your post

    Add a title, your text (Markdown works), tags, and images: PNG, JPEG, GIF, or WebP, up to {{ blog.limits.image_size_mb }} MB each and {{ blog.limits.images_per_post }} per post, with a short description of each one.

  3. Submit it

    {% if blog.review_visitor_posts %}Your post is checked automatically and published after I review it.{% else %}Your post is checked and published automatically.{% endif %} A comment on your GitHub issue tells you when it's live, or what to change first.

  4. Update it any time

    Edit the issue and the post changes too{% if blog.review_visitor_posts %}, after another review{% endif %}. Every post shows when it was published and when it was last updated.
