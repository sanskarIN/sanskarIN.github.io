How posting works

    {%- if accounts_on %}

  1. Sign in with your email

    Select "Write a post" and enter your email address. You get a 6-digit code by email, with no password to remember, and your account is created the first time. Then add your author profile: a display name and, if you like, a short bio and a website.

  2. Write your post

    Add a title, your text (Markdown works), tags, a cover image, and images in the text: PNG, JPEG, GIF, or WebP, up to {{ blog.limits.image_size_mb }} MB each and {{ blog.limits.images_per_post }} per post, with a short description of each one.

  3. Send it

    {% if blog.review_visitor_posts %}Your post is checked automatically and published after I review it.{% else %}Your post is checked and published automatically.{% endif %} Your account page shows when it's live, or what to change first.

  4. Update it any time

    Edit the post from your account page and the blog changes too{% if blog.review_visitor_posts %}, after another review{% endif %}. Every post shows when it was published and when it was last updated.

    5. {%- else %}

  5. Open the form

    Select "Write a post". The form opens on GitHub, where the blog's posts are stored, so you need a free GitHub account.

  6. Write your post

    Add a title, your text (Markdown works), tags, and images: PNG, JPEG, GIF, or WebP, up to {{ blog.limits.image_size_mb }} MB each and {{ blog.limits.images_per_post }} per post, with a short description of each one.

  7. Submit it

    {% if blog.review_visitor_posts %}Your post is checked automatically and published after I review it.{% else %}Your post is checked and published automatically.{% endif %} A comment on your GitHub issue tells you when it's live, or what to change first.

  8. Update it any time

    Edit the issue and the post changes too{% if blog.review_visitor_posts %}, after another review{% endif %}. Every post shows when it was published and when it was last updated.

    9. {%- endif %}
